PURE TCP RELAY + WEB ADMIN FINAL
================================

배포 기준
---------
- AdminMain.pas / AdminMain.exe는 더 이상 사용하지 않음.
- 관리 기능은 Web Admin만 사용.
- 기존 ApkWinSock / WinSockServer TCP Protocol 2는 변경 없음.
- 기존 Railway TCP Proxy (예: sakura.proxy.rlwy.net:33802)는 그대로 유지.

필수 Railway Variables
----------------------
ADMIN_SECRET=원하는 관리자 비밀번호
WEB_ADMIN_PORT=8080

권장 Railway Variables
----------------------
DATA_DIR=/data              (Railway Volume 사용 시)
STORAGE_ENGINE=sqlite       (기본값 / Node.js 22.13 이상)
OPERATOR_SECRET=...         (operator 계정이 필요할 때만)
VIEWER_SECRET=...           (viewer 계정이 필요할 때만)
VAPID_PUBLIC_KEY=...        (PWA Push 사용 시)
VAPID_PRIVATE_KEY=...       (PWA Push 사용 시)
VAPID_SUBJECT=mailto:...    (PWA Push 발신 주체)
DAILY_REPORT_TIMEZONE=Asia/Seoul
DAILY_REPORT_RETENTION_DAYS=365

Relay A/B HA 선택 변수
----------------------
HA_ENABLED=1
HA_INSTANCE_ID=relay-a
HA_PRIORITY=200
HA_PEER_URL=https://relay-b-admin.example.com
HA_SHARED_SECRET=양쪽에 동일한 32자 이상 랜덤 값
HA_POLL_MS=2000
HA_FAILOVER_TIMEOUT_MS=10000

Legacy TCP Admin
----------------
기본값: DISABLED
AdminMain.exe용 TCP Admin은 기본적으로 차단됨.
정말 예전 TCP Admin을 다시 써야 할 때만 아래 변수를 추가:
ENABLE_LEGACY_TCP_ADMIN=1

Web Admin Railway 설정
----------------------
1. GitHub 저장소 최상위에 server.js / package.json / public / web 등이 위치하도록 업로드.
2. Railway 새 Deployment가 SUCCESS인지 확인.
3. Railway HTTP Domain의 Target Port를 WEB_ADMIN_PORT(기본 8080)로 지정.
4. 브라우저에서 https://<railway-domain>/ 또는 /index.html 접속.
5. Role=admin, Password=ADMIN_SECRET 값으로 로그인.

Web Admin 주요 기능
-------------------
Dashboard
- Server / Client / License / ACK / Service / Version / 최근 이벤트

Servers
- Detail
- Kick 60s
- Drain ON/OFF
- Disable/Enable
- 상태/Health/RTT/Client 수/Version/IP/Reconnect

Clients
- Detail
- Notice
- Move
- Kick 60s
- Disable/Enable
- License/Server/RTT/Send/Auth/Reconnect

Client Move 안전 조건
---------------------
대상 Server가 아래 조건을 모두 만족해야 이동 가능:
- ONLINE
- DISABLED 아님
- DRAINING 아님
- KICKED 아님
- 정원 초과 아님
- 현재 Server와 다른 Server

Licenses
- Create/List/Search
- Extend/Unbind/Suspend/Resume/Reissue/Transfer/Delete
- Bulk Extend/Unbind/Suspend/Resume/Delete

Backups
- Create/List/Restore/Delete

System
- Service Start/Stop
- Maintenance ON/OFF
- Maintenance Schedule/Clear
- Notice All
- Version Policy

Primary / Backup Binding
- Client별 Primary / Backup Server 지정
- 지정 Backup 우선 Failover
- Backup 불가 시 자동 대체 허용 여부 설정

Request Recovery
- Offline Queue 전체 정책 + Client별 opt-in
- FIFO / TTL / Delivery Attempt 제한
- Request Trace Replay (항상 새 Request ID)
- Dead Letter Queue Retry / Discard

로그인 정책
-----------
- 로그인 실패 횟수에 따른 시간 차단 없음.
- LOGIN_RATE_LIMIT 없음.
- ADMIN-SECRET-KEY-1234 같은 기본 비밀번호 없음.
- ADMIN_SECRET가 설정되지 않으면 admin 로그인 자체가 비활성화됨.
