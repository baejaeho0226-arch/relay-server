PURE TCP RELAY vNext - WEB ADMIN 배포

1. 기존 TCP Relay 설정은 그대로 유지합니다.
   - WinSockServer / ApkWinSock 코드 변경 없음
   - 기존 Railway TCP Proxy도 그대로 유지

2. Railway Variables
   필수:
   ADMIN_SECRET=강력한관리자비밀번호

   선택:
   OPERATOR_SECRET=운영자비밀번호
   VIEWER_SECRET=조회전용비밀번호
   WEB_ADMIN_PORT=8080
   WEB_ADMIN_SESSION_MS=1800000

   주의:
   ADMIN_SECRET이 기본값 ADMIN-SECRET-KEY-1234인 경우 Web Admin 로그인은 기본적으로 차단됩니다.

3. Railway Web Domain
   - HTTP/HTTPS Domain의 Target Port를 WEB_ADMIN_PORT와 동일하게 설정합니다.
   - 예: WEB_ADMIN_PORT=8080 -> Domain Target Port 8080
   - 기존 TCP Proxy Target Port는 Relay TCP PORT 쪽을 그대로 사용합니다.

4. 실행
   npm run check
   npm start

5. 정상 시작 로그 예
   PURE TCP RELAY vNext
   TCP Port: ...
   Web Admin HTTP Port: 8080

6. 접속
   Railway에서 생성한 HTTPS Domain을 브라우저로 엽니다.
   Admin / Operator / Viewer 중 설정한 Role로 로그인합니다.

7. 보안
   - 비밀번호는 HTML/JS에 저장하지 않습니다.
   - 로그인 성공 후 HttpOnly + SameSite=Strict 세션 쿠키를 사용합니다.
   - 변경 API는 CSRF Token을 추가로 검사합니다.
   - Web Admin 세션은 Node 재시작 시 모두 만료됩니다.

8. 기존 AdminMain.exe
   TCP Admin 기능은 삭제하지 않았으므로 당분간 AdminMain.exe와 Web Admin을 동시에 사용할 수 있습니다.
   Web Admin 안정화 후 필요하면 TCP Admin을 제거할 수 있습니다.
