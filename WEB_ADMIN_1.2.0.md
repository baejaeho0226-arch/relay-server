# Web Admin 1.2.0

- License single Delete: typed `DELETE` confirmation removed. Normal danger confirmation modal only.
- License Bulk Delete: typed `DELETE` confirmation removed. Separate danger confirmation modal remains.
- Backup Restore/Delete, Service Stop, Version Apply confirmations remain intentionally protected.
- Hacker-console UI theme: terminal typography, neon green/cyan accents, scanlines, grid background, terminal navigation, compact status panels.
- Static assets use Cache-Control: no-store.
- Existing Relay TCP protocol is unchanged.
